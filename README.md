### What I'm building now (October 2026)

**An agent estate with gates that can fail.** 233 agent definitions and 40 declared MCP servers
(23 connected). The gates matter more than the numbers: a pin gate that checks every model pin
still resolves against the live registry, a freshness gate that checks the rules files still
describe the machines they govern, and a TDD gate that refuses production code without a test.
When one of those goes red on healthy work, the gate gets fixed, not the story.

**A betting analysis lane that measures itself.** A goals model, calibration over 1,095 de-vigged
observations, and one hard admission rule: a selection only goes in at 70% or better model
probability. A pre-placement gate enforces ten rules and has refused my own book on merit rather
than let it through. 980 automated tests.

**A trading system whose safety defaults off.** MT5 integration behind a live-trading gate, a
daily-loss cap, a mandatory stop on every position, and a kill switch that persists across
restarts with no in-chat way to reset it: once tripped, a human edits the state file by hand.
Alongside it runs a pre-execution hook that judges every shell command and file write before it
happens, and fails open rather than locking the machine.

**Smaller builds that earn their keep** — a Roblox game with its own test suite, and the MCP
servers pinned below.

### How I work

- **Verify on disk, never from the agent's own summary.** A bridge tool once reported a job
  complete and returned a plausible description of a deliverable that did not exist.
- **Write the rubric before the work.** A rubric written afterwards is shaped by the output it is
  meant to judge.
- **Every countable claim traces to something that re-measures it.** If a number cannot be
  re-measured on demand, it does not go in the document.
- **Keep the failures.** Every failure that cost real time or real money gets a numbered lesson —
  thirty-four so far.
- **Concede the limit before the reader finds it.** The fastest way to be trusted about what you
  can do is to be precise about what you cannot.
